## 3. Page and fragment with parameters

`th:fragment="helloworldparams(greeting, greetee)"` — the page passes `greeting`
literally and `greetee` from the `?greetee=` request parameter (via the
controller).

## 4. Content / slot parameter

When HTML needs to be passed into a component. The page wraps the slot markup in
an element with an id and passes it as a fragment expression
(`~{::#slot/content()}`); the component decides where it goes with
`<th:block th:replace="${content}">`.
