How to assemble a whole page — for Multi Page Applications or a single page.

## 1. Content Page

A reusable `layout` fragment supplies `<html>`, `<head>` and the container; the
page provides only the content it should wrap
(`th:replace="~{fragments/layout :: page('Content Page', ~{::pageContent})}"`).

## 3. Custom Page taking a parameter

When the opinionated content page does not fit: this page builds the whole
document itself and only reuses the small `page-head` fragment. The page has the
active role, not a layout.
