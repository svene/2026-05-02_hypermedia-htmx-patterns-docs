For reusable UI parts and components.

## 1. Parent Child

The parent fragment builds a chunk of slot markup (interpolating its own
`greeting` parameter) and passes it **down** into the child fragment via
`~{::#slot1/content()}`. Use when a child owns a large chunk of HTML and the
parent only customises a small part of it.

## 2. Forwarder

A fragment that, from its parameter, decides whether to render itself or delegate
to another fragment. (`th:if` wraps the `th:replace` in a separate element
because `th:replace` has the higher attribute precedence.)
