## 3. Page and fragment with parameters

The fragment declares `@param String greeting, String greetee`; the page passes
`greeting` literally and `greetee` from the `?greetee=` request parameter (via
the controller).

## 4. Content / slot parameter

When HTML needs to be passed into a component. The page passes a chunk of
markup as a `gg.jte.Content` parameter, written as a JTE content block; the
component decides where it goes just by referencing that parameter.
