How to assemble a whole page — for Multi Page Applications or a single page.
This is also where the project's original two hand-written patterns live now:
*Content Page* (d01) is the old Template-Injection demo, *Custom Page* (d03)
is the old Template-Inclusion demo.

## 1. Content Page

A reusable `layout` template supplies `<html>`, `<head>` and the container; the
page provides only the content it should wrap, passed as a `gg.jte.Content`
parameter to `@template.fragments.layout(...)`.

## 3. Custom Page taking a parameter

When the opinionated content page does not fit: this page builds the whole
document itself and only reuses the small `pagehead` fragment via a plain
`@template` call (no `Content` parameter). JTE does not allow unclosed tags, so
`pagehead` cannot itself open `<body>` for this page to close — the enclosing
tag lives in the consumer instead.
