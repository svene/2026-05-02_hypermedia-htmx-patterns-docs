For reusable UI parts and components.

## 1. Parent Child

The parent fills a named slot (`{#slot1}…{/slot1}`) that the child renders with
`{#insert slot1}{/insert}`. Use when a child owns a large chunk of HTML and the
parent only customises a small part of it.
