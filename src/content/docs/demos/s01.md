For basic usecases. Needs a spring-controller.

## Basic JTE Page

made using a JTE template.

[Demo](http://localhost:8081/page01)

```html title="page01.jte"
<h1>Application Page</h1>
```

```java title="PlainJTEController.java"
@Controller
public class PlainJTEController {
  public static final String PAGE_01_URL = "/page01";

  @GetMapping(PAGE_01_URL)
  public String app() {
    return "jte/plainjte/page01";
  }
}
```
